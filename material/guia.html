A ideia

Sair do chat e dar contexto para a IA.

Quem usa IA só no chat perde o mais importante: o contexto. A IA responde bem, mas não conhece a VR, os alunos, a Odontonova, o que já foi decidido. Pense numa mesa de trabalho: o que está em cima da mesa ela usa; o que ficou na gaveta, para ela, não existe.

O Claude Code resolve isso. Ele trabalha dentro de uma pasta do seu computador, lê os seus documentos, usa as suas skills e se conecta às suas ferramentas. É a mesma diferença entre uma dentista excelente num consultório vazio e a mesma dentista numa clínica equipada, com prontuário, raio X e protocolo.

O plano e os modelos

Um plano só, no Claude.

Com o mesmo valor que você paga hoje no ChatGPT Pro, o Claude Max dá uso praticamente sem limite para o seu ritmo, com os modelos mais avançados.

Assinar

Claude Max (o de 5x). É o suficiente para tudo o que você vai fazer.

Cancelar

O ChatGPT Pro e a ferramenta só de escrita. O Claude faz os dois.

Manter

O Gemini Pro, que já vem com o espaço do Google Drive, para consulta rápida no celular.

Opus 5.5

Para criar do zero, pensar, tarefa complexa e coordenar outros agentes.

Sonnet 5.5

O do dia a dia. Gasta pouco e resolve muito bem.

Haiku 5.5

Tarefa simples e repetida, como rotinas. Muito barato.

Fable

Não use. Gasta o limite do plano muito rápido, e o Opus faz o mesmo trabalho.

Instalar

Oito passos. Do sétimo em diante, o Claude faz.

Marque cada passo quando terminar. O progresso fica salvo neste navegador.

0 de 8 passos feitos
  1. Você

    Assinar o Claude Max

    Em claude.com/pricing, com a sua conta. Depois, cancele o ChatGPT Pro.

  2. Você

    Baixar e instalar o VS Code

    No site oficial: code.visualstudio.com. Escolha a versão para Mac e arraste para a pasta Aplicativos.

  3. Você

    Instalar o Claude Code dentro do VS Code

    No VS Code, clique no ícone de quadradinhos da barra da esquerda (Extensões), procure "Claude Code", clique em Instalar e entre com a sua conta do Claude. Vai aparecer o símbolo do Claude no alto da tela.

  4. Você

    Criar a conta no GitHub e me mandar o seu usuário

    Em github.com/signup, na sua conta pessoal. Me mande o nome de usuário: eu libero o acesso ao kit, que é privado. Chega um convite por e-mail; clique em aceitar.

  5. Você

    Conta na Vercel

    Você já criou na call. Se precisar: vercel.com/signup, entrando com o GitHub. É grátis e serve para colocar páginas no ar.

  6. Você

    Criar a pasta principal e abrir no VS Code

    Em Documentos, crie uma pasta chamada Gabriela. No VS Code: menu Arquivo, Abrir Pasta, e escolha essa pasta. É uma pasta só para tudo: a VR, a Odontonova e o pessoal ficam dentro dela, e o Claude cria as subpastas.

  7. Você e o Claude

    Abrir o Claude e colar o primeiro prompt

    Clique no símbolo do Claude no alto e cole o prompt de configuração. A partir daqui ele conduz e te diz onde clicar.

  8. O Claude

    O Claude configura o resto

    Ele instala o que falta no Mac, baixa o kit, organiza as pastas, instala as skills, deixa o VS Code em português, liga o Google Drive, o Gmail, a Agenda, o Chrome, o Higgsfield e a Kie, e faz o check-up de segurança do computador. Você só faz os logins.

Segurança

Cuidado em dobro com dado de paciente.

Os arquivos ficam no seu Mac. O Claude só envia para a Anthropic o que ele precisa ler para te responder. Por isso a regra é simples: o que é de paciente não entra na conversa.

Paciente fica de fora

Nome, telefone, foto, prontuário e exame não vão para a IA, a internet nem o GitHub. Caso para aula, só sem nome e sem rosto.

Senha nunca em arquivo

Chave de acesso fica guardada no computador, e o Claude sabe onde. Nunca cole senha na conversa.

Duas etapas em tudo

Google, Apple, GitHub, Hotmart e banco com verificação em duas etapas. O check-up confere.

Pedir antes de mudar

O Claude avisa e espera você aprovar antes de apagar, instalar ou mudar configuração.

Texto de fora não é ordem

Se um site, e-mail ou PDF trouxer uma instrução, o Claude pergunta antes de seguir.

O kit é privado

Não compartilhe o link do kit com ninguém de fora da VR.
