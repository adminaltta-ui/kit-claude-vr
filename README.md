# O kit do Claude da VR Concept

O kit que o João montou para a Dra. Gabriela começar no Claude Code com tudo o que a Altta já usa:
as skills, a biblioteca de marketing e vendas, e o contexto da VR Concept.

**O guia para ler e seguir** está em [material/guia.html](material/guia.html) (abra no navegador).

## O que tem aqui

| Pasta ou arquivo | O que é |
|---|---|
| `INSTALAR.md` | O roteiro que o Claude segue para configurar tudo. Você não precisa ler |
| `modelo-CLAUDE.md` | O manual fixo da sua pasta principal: quem você é, as empresas, as regras |
| `skills/` | As skills prontas para usar (veja a lista abaixo) |
| `Biblioteca/` | Os resumos de 24 livros de marketing, vendas, estratégia e retenção, mais artigos, vídeos e pesquisas |
| `VR Concept/` | Os documentos da empresa: o documento base, o aluno, a reestruturação e o logo |
| `referencias/` | As skills de marketing da Altta (modelo para criar as da VR), a pesquisa da tese da Sequoia e um exemplo de skill |
| `material/` | A apresentação da consultoria de IA e o guia |

## As skills prontas

| Skill | O que faz |
|---|---|
| `carrossel-vr-concept` | Do tema ao carrossel pronto em JPEG, na identidade da VR, com a legenda |
| `pesquisa-com-youtube` | Toda pesquisa junta a internet e o YouTube, lendo a fala dos vídeos |
| `consultar-biblioteca` | Antes de decidir, consulta os livros e as pesquisas e devolve uma recomendação com fonte |
| `guardar-na-biblioteca` | Transforma um livro, artigo ou vídeo num resumo guardado na Biblioteca |
| `pedido-para-o-joao` | Organiza uma ideia ou um problema num arquivo pronto para o João, com rascunho da tela |
| `html-premium-kit` | Páginas HTML bonitas e interativas de primeira |
| `manual-html` | Junta vários documentos num manual HTML para ler |
| `kie-models` | Gera imagem e vídeo pela Kie, comparando modelo e preço |
| `gauntlet-loop` | Revisão rigorosa antes de entregar, quando o trabalho precisa sair impecável |
